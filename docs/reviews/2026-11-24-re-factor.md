Subsequent headings govern their own claims, unrelated sections reset period context, and same sentence as well as concise answers remain accepted. 2. Explicit row metric precedence over table sections: Explicit row metrics in `classify_cell_metric` take precedence over inherited table section headers. 3. Blocker resolved: Clause desynchronization in `extract_financial_claims` has been resolved by splitting the unmasked text directly into clauses, then masking numbers inside each clause independently. Verified by `test_multi_sentence_beginning_with_date_does_not_desynchronize_claims`.
4. Major resolved: The redundant assignment branch in `parse_query_requirements` was removed. Backward propagation now only binds trailing qualifiers (introduced with `for`, `of`, `in`, or trailing at the end of the clause) to earlier unentitied metrics. Entity prefixes on second metrics remain properly isolated. Verified by `test_prefix_entity_on_subsequent_metric_does_not_bind_backwards`.
5. Minor resolved: Operations statement context in `classify_cell_metric` is tightened to require that the row label match a known segment entity or contain sales, revenue, or total keywords before classifying as `net_sales`.
6. Minor resolved: Abbreviated month names without days are now supported in `parse_date_components` (`m_my` pattern), correctly extracting month integers for strings like `Jun 2026`. Verified by `test_abbreviated_month_year_parsed_correctly`.
