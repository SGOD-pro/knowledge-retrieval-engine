## Minor
### 🟡 [Resolved] Unguarded empty string probe match in table scoring, `backend/src/services/retrieval/structured_query_service.py:250`
**Problem**: In `_score_candidate_tables`, `explicit_terms` extracted from query patterns (such as empty parentheses or quotes) can evaluate to empty strings after stripping. An empty probe term satisfies `exp_lower in val` for every table cell encountered, unconditionally adding 10 points to table scores.
**Why it matters**: Degenerate queries containing empty parentheses or empty quotes could falsely inflate table scores and distort candidate disambiguation.
**Resolution**: Filtered `explicit_terms` with `len(t.strip()) >= 2` and skipped any trimmed probe term with length under 2 characters before checking rows.
