## Minor
### 🟡 Unmanaged background thread creation for OKF graph extraction, `backend/src/ingestion/parse_service.py:146`
**Problem**: In `ingest_document`, line 146 starts an unmanaged daemon thread `threading.Thread(target=build_okf, args=(doc,), daemon=True).start()` for every ingested document.
**Why it matters**: Spawning unmanaged operating system threads during concurrent batch uploads can cause thread starvation and high memory pressure under sustained ingestion load.
**Suggested fix**: Manage OKF extraction tasks through a bounded worker thread pool or background task executor.

### 🟡 Inconsistent counting units in DocumentSnapshot for PDF vs CSV, `backend/src/modules/documents/documents_service.py:151`
**Problem**: In `DocumentSnapshot`, `persisted_rows` for PDF documents is assigned the chunk count `len(document.chunks)` while `total_rows` is assigned `len(document.chunks) + len(exclusions)` where exclusions are skipped pages.
**Why it matters**: Conflates paragraph chunk counts with page level exclusion counts under row based field names.
**Suggested fix**: Standardize terminology across structured tables and unstructured documents, or document that row fields represent chunk counts for paginated documents.
