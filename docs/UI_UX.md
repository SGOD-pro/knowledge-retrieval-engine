# KRE UI/UX Contract

## Scope
Included because the current repository has a frontend. Load only for frontend tasks.

## User Surfaces
Authentication, workspaces, document library/upload, chat/query workspace, document viewer, knowledge graph, benchmark/system views.

## Trust Signals
Show answer status, completeness/partial state, source format, location, calculations, conflicts and unsupported/incomplete status where relevant.

## Citation UX
PDF: page/bounding box when supported.
DOCX/PPTX/XLSX/CSV/HTML: format-specific locator.
Structured execution: operation, selected scope, result, units and lineage reference.

## Do Not Misrepresent
Confidence is metadata, not proof. The Knowledge Map/graph view is navigation context, not answer authority.
