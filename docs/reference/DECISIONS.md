# KRE Decision Register

- Baseline publication is independent of optional enrichment.
- Knowledge Map is routing metadata, not source truth.
- Structured execution is outside discovery RRF.
- RRF merges only compatible ranked discovery lists.
- Initial narrative reranking is fixed/bounded; adaptive skipping requires calibration.
- Query-time model work is globally budgeted before invocation.
- Mechanical and semantic verification are distinct.
- Answer support and request completeness are distinct.
- Lifecycle publication is immutable and generation-checked.
- CSV/XLSX execution uses registered immutable references and restricted typed operations.
