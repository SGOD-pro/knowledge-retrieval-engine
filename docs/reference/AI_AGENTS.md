# KRE AI/Agent Contract

## Roles
- Planner: requirements/contracts, not authorization.
- Router: Knowledge Map + capability readiness.
- Retrieval Coordinator: discovery branches.
- Structured Executor: safe deterministic data operations.
- Evidence Validator: mechanical + semantic support.
- LAYA: bounded route/expansion proposal.
- Answer Composer: deterministic template or bounded synthesis.

## Grounding
Agents must not guess material ambiguity, use rank as proof, or treat maps/summaries/LLM output as source truth.

## Handoffs
Carry workspace/query/snapshot/requirement identity plus explicit budgets/deadlines and outputs.

## Memory
Workspace evidence follows authorization. Conversation history is session-local by default.
