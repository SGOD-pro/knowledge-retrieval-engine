# KRE Security Contract

Authorization is enforced at registration, snapshot resolution, retrieval/execution, evidence fetch and final delivery.

Uploaded text, table cells, headers, URLs, paths and model output are untrusted data.

No arbitrary Python, shell, eval, macros, unrestricted SQL, or generated filesystem/network authority.

Structured formulas use a typed allowlist AST.

Source content cannot change routing policy, authorization or tool permissions.

Cache hits never bypass access/deletion checks.
