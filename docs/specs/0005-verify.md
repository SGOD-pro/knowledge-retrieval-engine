## Acceptance criteria coverage
- AC-1: Ingestion extracts and persists typed PageIndexManifest and PageIndexSummary per document version, capturing hierarchy, heading paths, page ranges, and verified definition targets with DocumentSnapshot status tracking.
- AC-2: PageIndex layout extraction and query lookup operate deterministically with exactly zero token usage, zero language model calls, and zero embedding invocations.
- AC-3: Soft reciprocal rank fusion pools structural candidates with calibrated weighting (1.1, divided to 0.55 on ambiguity) without hard candidate page exclusions or chunk pruning, preserving true factual evidence on unindexed pages.
- AC-4: Bounded storage persists manifests under 250KB inline in PageIndexSummary and offloads hierarchies over 250KB to S3 using S3 first sequencing, bounding root sections without silent truncation when summary overflows.
- AC-5: Dedicated socket configuration (30ms connect, 40ms read, explicit botocore retry disabling) and 50ms total deadline enforce bounded latency; admission gate bounds concurrency (4 workers, 8 queued submissions) and retains capacity until underlying storage completes.
- AC-6: Target discrimination distinguishes formal caption definitions from paragraph and table cell cross references, classifying duplicates as ambiguous and unformatted PDFs as missing layout.
- AC-7: Storage and lookups are partitioned strictly by workspace_id and document_version; cross workspace requests return 404 or empty results with zero tenant leakage; active source tombstones immediately block retrieval.
- AC-8: Dedicated administrative HTTP endpoints are deferred; structural candidate IDs, match count, latency, and target state are exposed exclusively in DocumentSnapshot and retrieval_candidates trace.
- AC-9: Offline ablation harness evaluates candidate page recall, precision, and latency with PageIndex enabled versus disabled across canonical evaluation documents.
- AC-10: Formal benchmark accuracy claims remain blocked until controlled canonical 60 question benchmark executes on ws_canonical_comparison_0004.
